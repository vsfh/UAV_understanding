\subsection{Current Development Diagnostics}
\label{sec:development_results}

The official provenance gate is still \texttt{BLOCKED}, so the following results are not benchmark test results and do not answer the unseen-site question. They are single-seed diagnostics on the complete 18-class subset of the provisional session-grouped split: 16,597 training-pool pairs, 2,384 validation pairs, 329 validation sessions, and 1,551 validation context sets. Training caps each class at 250 pairs per epoch. Pair and set thresholds are fitted and scored on this same validation partition; the numbers therefore diagnose the implemented pipeline but are optimistic estimates of generalization.

\input{table/development_results}

\paragraph{Zero-shot and view effects.}
Definition prompting improves OpenCLIP's score-based label-selection micro-F1 from 25.9 to 37.9, although its macro-F1 remains 11.3. In contrast, the Qwen3-VL free-generation definition prompt is indistinguishable from its direct prompt (8.1 versus 8.2 macro-F1). Label-only LoRA substantially improves all three adapted inputs. The evidence crop is far more informative than the wide context (66.7 versus 30.4 macro-F1), and the ordered context--evidence pair reaches 70.1. Relative to crop-only input, the paired free-generation gain is 3.4 macro-F1 points (95\% session-bootstrap CI, 0.4--6.6) and 1.5 micro-F1 points (0.3--2.7). Relative to context-only input, the gains are 39.7 (35.1--43.5) and 31.6 (28.4--34.9) points, respectively. Thus the local crop supplies most of the signal, while the wide view contributes a smaller but measurable free-generation gain on this split.

\paragraph{Decoder dependence.}
With normalized candidate likelihoods and independently fitted thresholds, paired input attains 60.7 macro-F1, 84.8 micro-F1, and 57.9 mAP. Its macro-F1 advantage over crop-only input is 3.2 points, but the grouped interval crosses zero ($-1.0$--6.8); its 2.2-point micro-F1 advantage has interval 1.0--3.4. Crop-only input also has better hard-negative accuracy (73.4 versus 64.3) and lower AURC (0.215 versus 0.251). The benefit of global context is therefore decoder-dependent and not uniformly established by this validation run.

\paragraph{Set aggregation.}
Max pooling is markedly stronger than log-sum-exp on the current 1,551 validation sets. For paired input it raises set macro-F1 from 30.2 to 62.8 and exact-set accuracy from 47.8 to 72.4; the same pattern holds for each single view. This comparison refits thresholds on the same validation sets and is not a held-out ablation. It nevertheless falsifies the current default assumption that smooth accumulation is automatically preferable: before any test run, the aggregation rule and thresholds must be frozen on a separate development partition.

\paragraph{What these runs do not establish.}
The adapted models use canonical label targets only. They do not use human-audited evidence statements, factor supervision, graph-neighbor margins, counterfactual unlikelihood, or view dropout, and hence are baselines rather than the full \method. Their initial suffix-based LoRA configuration also reached visual-block MLPs; corrected visual-tower-frozen reruns must replace these numbers. The pair run allows up to 262,144 pixels for each image, whereas a single-view run processes one image, so it is not a compute-matched complementarity test. GeoChat, the full ablation matrix, three-seed variation, explanation review, proposed crops, and official test evaluation remain unrun.
